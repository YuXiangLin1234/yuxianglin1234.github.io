# Yu-Xiang Lin — Personal Website

Personal academic website: https://yuxianglin1234.github.io/

This is a static website built with HTML, CSS, and JavaScript. GitHub Pages publishes the root of the `main` branch. No build tools, paid services, or analytics are required.

## Update

- `index.html`: biography, publication metadata, authors, and links.
- `styles.css`: layout and typography.
- `site.js`: copyright year.
- `assets/yu-xiang-lin.jpg`: profile photo.

Push changes to `main` to update the website automatically.
